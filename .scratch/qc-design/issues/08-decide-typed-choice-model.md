# Decide qc's typed choice model

Type: grilling
Status: open
Blocked by: 03

## Question

Given the findings on Hypothesis's typed choices, decide `qc`'s own: which choice types exist, what constraints each carries, how each public draw function maps to choices, how `qc_more` is expressed, and how a choice sequence is stored in memory in C99. Decide the in-memory representation only; the portable blob encoding stays fog until the failure database is designed.
